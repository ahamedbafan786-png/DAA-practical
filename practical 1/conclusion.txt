CONCLUSION - PRACTICAL 1: SORTING ALGORITHMS

In this practical, we implemented and analyzed fundamental sorting algorithms:
1. Bubble Sort: O(n^2) worst/average time complexity, O(1) space complexity. Optimized with a swapped flag for O(n) best-case performance on nearly sorted data.
2. Selection Sort: O(n^2) time complexity across all cases, O(1) space complexity. Minimizes the total number of element swaps.
3. Insertion Sort: O(n^2) worst/average time, O(n) best time, O(1) space complexity. Efficient for small or mostly sorted arrays.
4. Merge Sort: Guaranteed O(n log n) time complexity across all cases, O(n) space complexity. A stable divide-and-conquer sorting algorithm.
5. Quick Sort: O(n log n) average time complexity, O(n^2) worst case, O(log n) auxiliary call stack space. Efficient in-place sorting method.

Key Takeaways:
- Comparison-based sorting algorithms display clear trade-offs between execution speed and memory usage.
- Divide-and-conquer sorting techniques (Merge Sort & Quick Sort) significantly outperform quadratic O(n^2) algorithms on larger datasets.
