CONCLUSION - PRACTICAL 3: HEAP SORT ALGORITHM

In this practical, we implemented and analyzed the Heap Sort algorithm using a Max Heap data structure:

1. Heap Structure & Operations:
   - Heapify operation restructures binary trees in O(log n) time.
   - Initial Max Heap construction from an unsorted list runs in O(n) time.

2. Performance Metrics:
   - Time Complexity: Best: O(n log n), Average: O(n log n), Worst: O(n log n)
   - Space Complexity: O(1) auxiliary space (in-place sorting).

Key Takeaways:
- Heap Sort guarantees O(n log n) runtime bound regardless of initial input permutation.
- It combines the worst-case efficiency of Merge Sort with the O(1) space advantage of Insertion Sort.
